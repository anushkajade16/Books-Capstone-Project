Books to Scrape: Data Science Capstone

From web scraping to machine learning and a Power BI dashboard, using 1,000 book records.

About this project

I collected book data from the Books to Scrape website and studied book prices, ratings and availability. I cleaned the data, explored it with charts, built a simple machine learning model to spot highly rated books, and presented the results in a Power BI dashboard.

1,000 books collected
£35.07 average price
2.92 average rating
375 highly rated books

What I set out to do

  • Collect 1,000 book records using web scraping.
  • Clean and prepare the data for analysis.
  • Analyse book prices, ratings and availability.
  • Build a simple machine learning model to identify highly rated books.
  • Create a Power BI dashboard to present the findings.

Words used in this project

Web scraping
Using code to collect information from a website automatically.
EDA (Exploratory Data Analysis)
Looking at data with charts and numbers to find patterns.
Decision Tree
A machine learning model that makes a prediction by answering a series of yes/no questions.
Accuracy
How often the model's prediction was right on data it had not seen before.
Slicer
A filter in Power BI, for example to show only books with a 5-star rating.

How I built it

Step 1: Collect the data

I used Python with Requests and BeautifulSoup to scrape 50 pages of the Books to Scrape website. For each book I collected the title, price, availability and rating. The raw data was saved as Books_Raw_Data.csv.

Step 2: Clean the data

  • Checked for missing and duplicate values and removed duplicates.
  • Converted the price into a number.
  • Changed ratings from words (One, Two...) to numbers from 1 to 5.
  • Created price categories (Low, Medium, High) and rating categories.
  • Saved the result as Books_Cleaned_Data.csv.

What the charts show

Book rating distribution

Ratings are spread across all 1 to 5 stars. Books with a 1-star rating are the most common (226), and 4 stars is the least common (179).

Book price distribution

Prices run from £10 to about £60, and books are spread fairly evenly across that range.

Price vs rating

Books at every rating level appear across the whole price range, so a higher price does not clearly mean a higher rating.

Books by price category

About 403 books are in the High group, 401 in Medium and 196 in Low. No book fell into the Very High group.

Book price box plot

The middle (median) price is about £36. The box shows where the middle half of prices sit, and no unusual outliers appear.

Machine learning model

I used a Decision Tree Classifier to predict whether a book is highly rated based on its price.

  • Goal: High_Rating is 1 if the rating is 4 or 5, and 0 otherwise.
  • Input: Price.
  • Split: 80% of the data for training, 20% for testing.
  • Result: 58.5% accuracy on the test data.

Conclusion: Price alone is not enough to identify highly rated books. More features could improve the model.

Power BI dashboard

Page 1: Book data analysis

Shows four numbers at the top (total books, average price, average rating, highly rated books) and charts for rating, price, price category and price vs rating. Slicers let you filter the charts.

Page 2: Book details

A table of individual books with rating and price category slicers. You reach it with drill-through from the main page.

Power BI features used: drill-through, bookmarks, sync slicers and row-level security (RLS).

What I learned

  • Price alone is not enough to predict a book's rating.
  • Adding more useful features could improve the model.
  • The dashboard makes it easy to compare book prices and ratings.

This project gave me hands-on practice in web scraping, data cleaning, EDA, machine learning and Power BI.
